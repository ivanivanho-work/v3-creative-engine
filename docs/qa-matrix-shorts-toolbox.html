Shorts Toolbox What it is, who it's for, and how the apps connect

The Shorts Toolbox is a suite of internal Google tools built for the APAC Shorts Marketing team. It covers the full lifecycle of a YouTube Shorts campaign: intelligence gathering, campaign creation, asset generation, and performance optimisation.

Known Quirks & Things to Watch

JP Proactive Container - Special Handling

This campaign category has an explicit mapping in the code to force it into the Always-On tab under the Japan market. If this mapping breaks, JP Proactive Container data will not appear in the dashboard. Verify it appears in the correct sub-tab after upload.

Date Format Sensitivity

The CSV parser supports MM/DD/YYYY, DD-MM-YYYY, and YYYY-MM-DD. If dates arrive in an unexpected format, they silently fall back to null and the row may be excluded from calculations. Always verify the date column format in source CSVs before upload.

Firestore Chunking Limit

Data is saved in chunks of 100 rows to stay within Firestore's 1MB document limit. Extremely large datasets (>1000 rows) will produce many chunk documents. If a save is interrupted mid-chunk, partial data may be loaded on the next open. A full re-upload is the fix.

GenAI DAU-SCT Visibility Rule

This metric is only shown for campaigns in the GenAI Hub or for anchor rows. It is intentionally hidden for all other campaign types. This is expected behaviour, not a bug.

Pause State Logic for "Total" Demographic

The "Total" (GenPop) row is only marked as Paused if BOTH the male AND female rows in the same age bucket are paused. If only one gender is paused, Total remains active. This is intentional and must not be changed.

Market Resolution Default

If the app cannot resolve a campaign's market from the CSV data or metadata, it defaults to India. This means incorrectly formatted CSVs could silently assign campaigns to the wrong market. Always validate market column values in source files.

Known Quirks & Things to Watch

AUNZ Market - Not in UI

AUNZ is defined in the database schema and constants but is NOT shown in the market selector in the current UI. If AUNZ data is uploaded, it will be stored but not visible to managers. This is a known gap, not a bug in the traditional sense, but needs to be clarified before launch.

Scoring Settings Take Effect Next Week

Changes made in the Scoring Settings tab are saved but only applied during the next Monday scheduler run. They do not retroactively change the current week's rankings. If a manager adjusts weights on Tuesday, they will not see any change until the following Monday.

Upload Rate Limit Behaviour

The API enforces a hard limit of 20 uploads per hour per IP (no auth). The 21st upload within an hour will be rejected with a 429 error. The error message should be tested to ensure it is user-friendly and not a raw HTTP error code.

MCP Bridge - Critical Integration

The approval action in the dashboard triggers a push to the Agent Collective via MCP Bridge. This integration must be verified end-to-end before launch. If the push fails silently, a topic appears approved in the UI but no campaign brief is generated.

Gemini AI Key Dependency

All AI processing (normalization, deduplication, embedding generation) depends on the GEMINI_API_KEY secret being configured correctly in Cloud Functions. If the key is missing or expired, uploads will fail at the processing stage. Topics will remain in "raw" status indefinitely and never appear in the dashboard.

Public Upload Tab - No Auth

The upload tab intentionally requires no authentication so external agencies can submit data without Google accounts. However, the /api/topics endpoints for read/write by managers are admin-only. These two access tiers are separate by design.

Known Quirks & Things to Watch

Admin Dashboard Shows Aggregated Events - Not Real-Time Per-User

The dashboard aggregates all usage_events. There is no per-user breakdown. If two users are using Shorts Brain simultaneously, their events are counted together. This is by design.

KPI Tiles Depend on Event Logging in All Tools

If any tool stops logging events to /usage_events (due to a deployment issue or code change), the corresponding KPI tile will appear as zero. Always verify event logging is working after any deployment to any tool.

Hub Portal Links Must Match Firebase Hosting Routes

Each tool card on hub.html links to a specific URL path. If the Firebase Hosting configuration changes a URL or adds/removes a rewrite rule, the hub.html links will break. Verify all navigation links after any hosting config change.

"Campaign Learnings Agent" Placeholder

The Hub Portal shows a "Campaign Learnings Agent" card in the Performance track. This tool is marked "coming soon" and is not built. The link should either be disabled or clearly marked as unavailable. Do not test this as a functional feature.

Known Quirks & Things to Watch

Market Lock - Cannot Change Mid-Session

The market dropdown disables the moment the first message is sent. If the user selects the wrong market, the only fix is to start a completely new session. There is no mid-session market switch.

Concurrent Session File Collision

If two users run the pipeline for the same market simultaneously, market-level "latest_*" files in the output folder can overwrite each other. Session-keyed copies are the fallback, but the "latest" pointer may be wrong. Avoid running two sessions for the same market at the same time.

Stall Detection - Manual Recovery Only

If the SSE stream completes but no renderable output was produced, the phase indicator shows a stall warning. There is no automatic retry. The user must click "Start over" and re-run the pipeline from scratch.

Template Mode - Overlaid on Create and Full Campaign

If the campaign's featured Shorts Creation Tool matches an entry in the TEMPLATE_CATALOG (currently only "Photo to Video"), the pipeline automatically sets a template_schema in session state. All downstream agents use it to constrain scene types and assign Remotion slot IDs. The manifest produced will include a template_id field, which triggers a direct handoff to Template Stamper when loaded in Creative Generator.

Gemini Output Wrapping - Automatically Stripped

Gemini sometimes wraps JSON responses in markdown code fences (```json ... ```). The pipeline strips these automatically via internal parsing. This is expected and not a bug, but if an agent output looks malformed in the chat, the raw response may have an unexpected wrapping format.

KB Passcode Required for File Management

Uploading or deleting KB files requires a passcode. The passcode is not stored in the codebase. If the passcode is lost, KB file management is blocked entirely. Ensure the passcode is documented securely before deploying to production.

Known Quirks & Things to Watch

Reference Gating - Jobs Cannot Run Until All Refs Complete

Jobs that reference specific reference images are blocked until those references reach "completed" status. Clicking "Generate" on a blocked job does nothing. Always run "Generate All" on the Reference View first and wait for all refs to complete before moving to the Job View.

Video Jobs Can Take Up to 5 Minutes Each

Veo 3.1 video generation is asynchronous. Each video is polled every 10 seconds for up to 300 seconds. If a campaign has many video jobs, total generation time can be significant. Plan for this in QA testing time estimates.

Session Expiry Requires Re-Upload

If the backend session expires due to inactivity, the frontend receives a 404 on polling and auto-creates a new session. However, the new session starts empty - the manifest must be re-uploaded. Archived runs in the sidebar do allow restoring, but they create a fresh backend session, not a true resume.

Manifest Version Must Be Exactly 1.1

The manifest validator rejects any manifest where manifest_version is not exactly "1.1". If Agent Collective produces a manifest with a different version (e.g. due to a code update), Creative Generator will not accept it. Check the version field in the manifest before handing off between the two tools.

All Text Items Must Pass Quality Check (fits_limit=true)

If any text item in the manifest has fits_limit=false, the manifest fails validation and cannot be loaded. This means the Agent Collective prompt quality loop must have passed before the manifest is exported. A manifest with a failed quality check cannot be "forced through" Creative Generator.

Template Handoff Failure is Non-Blocking

If the POST to Template Stamper fails after generation is complete, the handoff file is saved to GCS with a "partial" status. The generation session is still marked complete. The template handoff can be retried manually by POSTing the saved template_handoff.json to Template Stamper directly.

Template Stamper Branded Video Generation from Remotion Templates

React 18 + TypeScript Remotion Lambda (AWS) Firebase Storage React Router Creative Operations Template Admins

What it does: Template Stamper takes pre-designed Remotion video templates and fills their variable slots with images, videos, and text to produce branded vertical video ads (9:16, ~17 seconds). It is the final step in the pipeline when a campaign is running in "template mode" - receiving assets from Creative Generator and rendering them as polished branded videos.

Capacity target: 64 videos per month across 4 markets (16 per market), rendered at 1-2 minutes per video via Remotion Lambda.

How It Connects to Creative Generator

Template Stamper receives a template_handoff.json file either automatically via webhook (POSTed by Creative Generator on session completion) or manually uploaded by the user. This file contains the template ID, slot mappings, and asset URLs from the generation run.

Template Mode Must Be Active in Agent Collective

Template Stamper only receives jobs when the Agent Collective pipeline was run in "template mode" - i.e., the campaign's featured Shorts Creation Tool matched an entry in the TEMPLATE_CATALOG (currently only "Photo to Video"). If template mode was not active, no handoff is sent and Template Stamper is not used for that campaign.

Remotion Lambda Runs on AWS, Not GCP

Remotion Lambda uses AWS Lambda for rendering - it is not a Firebase or GCP service. This means AWS credentials, a deployed Remotion Lambda function, and proper IAM permissions must all be in place separately from the GCP deployment. Verify the Remotion Lambda deployment and AWS configuration as a critical pre-launch step.

Markets Are Different From Agent Collective

Template Stamper serves Japan, Korea, Taiwan, and Hong Kong. Agent Collective serves Korea, India, Japan, and Indonesia. Taiwan and Hong Kong are not in Agent Collective; India and Indonesia are not in Template Stamper. This is intentional but can cause confusion when tracing a campaign end-to-end. Confirm with the team which markets are in scope for the full pipeline handoff.

Generate Button Has No Visible Error State

If the job creation API call fails, the button returns to "Generate Video" without showing an error message (based on current code). The user may not know the job was not created. Verify error handling on the Generate button is surfaced clearly in the UI.

No Batch Job Creation Yet

The current API only supports creating one job at a time via /api/jobs/create. There is no batch endpoint. If a campaign needs 16 videos for one market, each must be triggered individually through the Generate page.
